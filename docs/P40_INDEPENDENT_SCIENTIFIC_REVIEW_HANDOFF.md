# P40 Independent Scientific Review Handoff

P40 prepares a traceable decision ledger for Nikolas and an independent scientific reviewer. It **does not approve** biomarkers or modify application behavior.

## Baseline

- 216 P37 source entries (117 immune, 99 behavioral).
- 54 P39 proposed semantic relationships; 162 entries without curated candidates.
- All 216 decisions remain pending; zero operational approvals.
- P35.5 catalog has titles without units, so unit equivalence cannot be established from the current catalog.

## Required review procedure

For each candidate, the reviewer must assess biological equivalence, specimen, assay/method, units, sampling protocol, mission phase, measurement quality, provenance and interpretation limitations. A broad panel or domain-level catalog title must not be treated as an interchangeable individual analyte.

Record reviewer identity, dated decision, evidence reference and explicit rationale in a separately reviewed change proposal. Never change the P40 baseline ledger silently. Any accepted alias remains a **documentary scientific mapping** only, not a clinical rule or activation.

## Explicit remaining gates

Independent scientific sign-off, real-device offline OCR airplane-mode evidence, and any separate mission/production acceptance gates remain outstanding. No database migration, cloud write, clinical activation, publication or deployment is authorized by this patch.
