# Competition PDF navigation handoff

Adds three public GitHub PDF links under **About & Open Source → Competition documents (PDF)**. These are the **existing Final Competition Edition PDFs**, not the newer Claude revisions currently in preparation.

The PDFs must be committed and synced to GitHub `main` before the links work. They are publicly accessible through GitHub without sign-in if the repository is public. Verify all three links in a signed-out browser. If the repository is private, public evaluators cannot open the files.

No database, authentication, clinical, scientific approval, or deployment changes. Later replace these PDFs with Claude's reviewed final releases using a separate, explicit documentation update. The menu labels and filenames can remain stable.

The GitHub viewer may display or offer to download the PDFs depending on file size and browser.
