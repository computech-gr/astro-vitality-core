# Competition PDF navigation handoff

Adds three public GitHub PDF links under **About & Open Source → Competition documents (PDF)**. These are the **FINAL release PDFs** in `docs/competition/`: `MITOCHONDRIA_Master_Operations_Technical_Manual_FINAL.pdf`, `MITOCHONDRIA_NASA_Evaluator_Quick_Start_Guide_FINAL.pdf`, and `MITOCHONDRIA_NASA_Space_Apps_2026_Presentation_FINAL.pdf` (the earlier Final Competition Edition PDFs were replaced on GitHub `main`).

The PDFs must be committed and synced to GitHub `main` before the links work. They are publicly accessible through GitHub without sign-in if the repository is public. Verify all three links in a signed-out browser. If the repository is private, public evaluators cannot open the files.

No database, authentication, clinical, scientific approval, or deployment changes. Replacing these PDFs with newer releases is a separate, explicit documentation update; the menu labels can remain stable while the filenames change with the documents.

The GitHub viewer may display or offer to download the PDFs depending on file size and browser.
