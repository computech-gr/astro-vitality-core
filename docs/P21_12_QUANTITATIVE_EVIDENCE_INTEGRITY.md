# P21.12 — Quantitative Evidence Integrity & Challenge Translation

## Purpose

P21.11 contains four **qualitative** source-located findings from one inspected terrestrial bed-rest analog full text (PMID 25107989). P21.12 creates a strict, machine-checked extraction queue for those four findings, **not** a claim that quantitative values have been extracted. The other five studies retain their P21.11 access statuses.

## Quantitative extraction gate

For each effect, obtain the original table/figure, specimen and assay, exact units, denominator, study arm, comparator, timepoint, estimate, uncertainty, and a second-person transcription check. Record non-comparability and possible confounders. Do not transform urinary CTX into serum CTX, pooled analog results into ISS-specific risk, or biomarker change into BMD loss.

## NASA challenge alignment

- Gather: preserve source, time, assay/device, unit, quality and provenance.
- Evaluate: compare only compatible measures, disclose uncertainty and applicability to astronaut populations.
- Act: present non-diagnostic context and mission-protocol escalation only after explicit review; no automatic treatment advice.
- Follow-up: track repeat measurement or flight-medical referral according to an approved mission protocol.

These are **design acceptance criteria**, not new application functionality. No thresholds, automated recommendations, clinical actions, scientific approvals, or code changes are introduced.

## Next step

An independent scientific reviewer should validate full-text numeric transcriptions and applicability. Separately, implement and demonstrate the challenge's Gather → Evaluate → Act → Follow-up user journey using synthetic data and safe guidance before expanding the clinical evidence base.
