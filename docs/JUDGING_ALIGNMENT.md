# P20 Judging Alignment

The 2026 project is designed to be judged on documented evidence rather than unsupported claims.

The current official 2026 challenge page identifies the challenge as **Create Health Monitoring Software for Astronauts on Space Missions**. The controlled project baseline targets a demonstrable astronaut-facing monitoring and decision-support loop.

The current public Space Apps awards framework includes categories such as Best Use of Science, Best Use of Data, Best Use of Technology, Galactic Impact, Best Mission Concept and Best Use of Storytelling. This document does not rank the project or claim eligibility for a specific award; it identifies where evidence exists for judges to inspect.

| Evidence theme              | Project evidence                                                                 |
| --------------------------- | -------------------------------------------------------------------------------- |
| Scientific defensibility    | Reviewed Biomarker Matrix v1.1, scientific governance, explicit limitations      |
| Technology                  | Device adapter SDK, canonical model, offline encrypted runtime, governed backend |
| Mission concept             | Crew autonomy, local critical path, Mission Day 127 end-to-end story             |
| Storytelling                | Controlled 3-minute narrative and deterministic fallback                         |
| Open data / reproducibility | Synthetic dataset, citations, open-source repository, release-candidate workflow |

The official 2026 submission/judging checklist must be re-verified before final submission; the repository must not assume that prior-year form fields or judging procedures are unchanged.
