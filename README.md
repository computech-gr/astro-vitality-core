# Astro Vitality Core

Create a new project named Mitochondria for an open-source, offline-first astronaut health intelligence platform for NASA Space Apps Challenge 2026.

This is P2 foundation only. Do not build the health dashboard, authentication flows, medical features, sensor integrations, AI health logic, database schema, or Supabase tables yet.

Establish only a clean production-grade web application foundation suitable for later connection to the existing GitHub repository computech-gr/mitochondria and the existing Supabase project mitochondria.

Requirements:

 TypeScript

 React

 Vite

 responsive application shell

 PWA-ready architecture, but do not implement offline health-data storage yet

 clean separation between UI, application logic, domain logic, integrations, and infrastructure

 no hardcoded secrets

 no real astronaut or medical data

 no mock medical claims or diagnostic logic

 production canonical origin: https://mitochondria.edocinfo.com

 Lovable preview URLs must never be treated as the canonical production origin

 keep the initial UI intentionally minimal; this phase is architecture and repository foundation, not product UI design

Do not create Supabase migrations or database objects yet.

Do not add unnecessary dependencies.

Create the initial project and report exactly what files and dependencies were created. Do not proceed beyond this scope.
